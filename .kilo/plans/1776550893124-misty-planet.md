# Plan: GitHub Integration & Framer Integration for ArtifyPro

## Goal
Add GitHub integration for code export and Framer integration (both export and animations) to the ArtifyPro design editor.

---

## 1. GitHub Integration for Code Export

### Overview
Implement pushing exported code directly to a user's GitHub repository using the GitHub API (REST or GraphQL).

### Implementation Steps

#### 1.1 Add GitHub OAuth/API Library
- **Package**: Install `octokit` in `artifypro` (GitHub SDK)
- **Location**: `artifypro/package.json`

#### 1.2 Create GitHub Service
- **File**: `artifypro/src/services/githubService.ts`
- **Functions**:
  - `authenticateWithToken(token: string)`: Initialize Octokit with user's token
  - `getUserRepos()`: Fetch user's repositories
  - `createOrGetRepo(owner: string, repo: string)`: Create new or get existing repo
  - `pushFiles(owner: string, repo: string, files: ExportFile[], branch: string)`: Push exported files to repo
  - `createCommit(owner: string, repo: string, message: string, files: ExportFile[])`: Create commit with files

#### 1.3 Add GitHub Authentication Component
- **File**: `artifypro/src/components/GitHubAuthModal.tsx`
- **Features**:
  - Input field for GitHub Personal Access Token (PAT)
  - Option to create new repo or push to existing
  - Repository name input
  - Branch selection (default: main)

#### 14. Update ExportPanel
- **File**: `artifypro/src/components/ExportPanel.tsx`
- **Changes**:
  - Replace `pushToGitHub` placeholder with full implementation
  - Add state for GitHub auth (token, selected repo)
  - Add loading states during GitHub operations
  - Add success/error feedback to user

#### 1.5 Environment/Config
- No backend required - all GitHub operations can be done client-side using user's PAT
- Optionally add GitHub OAuth app flow for better UX (future enhancement)

## 2. Framer Integration - Export to Framer

### Overview
Enable users to export their designs directly to Framer.com using Framer's API/import functionality.

### Implementation Steps

#### 2.1 Research Framer Import Options
- **Option A**: Use Framer's embed API to generate shareable link
- **Option B**: Export as format Framer accepts (Figma/JSON)
- **Option C**: Generate Framer-compatible React code that can be copied to Framer projects

#### 2.2 Implement Framer Export Service
- **File**: `artifypro/src/services/framerService.ts`
- **Approach**: Export as Framer-compatible React component with Framer Motion animations
- **Functions**:
  - `generateFramerCode(files: ExportFile[])`: Convert export to Framer-compatible code
  - `openInFramer()`: Open Framer with the generated code (via clipboard or new tab)

#### 2.3 Update ExportPanel
- **File**: `artifypro/src/components/ExportPanel.tsx`
- **Changes**:
  - Replace `openInFramer` placeholder with implementation
  - Generate code compatible with Framer's component structure

## 3. Framer Integration - Add Framer Motion Animations

### Overview
Add Framer Motion animations to the ArtifyPro editor UI components for enhanced user experience.

### Implementation Steps

#### 3.1 Install Framer Motion in artifypro
- **Package**: Add `framer-motion` to `artifypro/package.json`
- **Version**: Use compatible version with React 19

#### 3.2 Add Animations to UI Components

**Toolbar (artifypro/src/components/Toolbar.tsx)**
- Add spring animations for tool selection
- Animate tool icons on hover/click
- Motion path for active indicator

**PropertiesPanel (artifypro/src/components/PropertiesPanel.tsx)**
- Animate panel open/close with `AnimatePresence`
- Smooth height transitions when expanding sections

**LayersPanel (artifypro/src/components/LayersPanel.tsx)**
- Animate layer reordering with `Reorder`
- Drag animations for layer items

**ExportPanel (artifypro/src/components/ExportPanel.tsx)**
- Animate modal entrance (scale + fade)
- Animate format selection cards on hover

**GeneratePanel (artifypro/src/components/GeneratePanel.tsx)**
- Animate suggestions appearing with stagger
- Animate loading states

**MultiplayerUI (artifypro/src/components/MultiplayerUI.tsx)**
- Animate cursor presence indicators
- Animate user join/leave notifications

#### 3.3 Create Animation Constants
- **File**: `artifypro/src/constants/animations.ts`
- Reusable animation variants for consistent UI
